# Common issues

Gotchas discovered while setting up and baselining this repository. Add new ones here.

| Symptom | Cause | Fix |
|---|---|---|
| Frontend tests or `yarn` behave oddly / `task validate:node` fails | Wrong Node major (upstream CI uses 22; newer Node can break jsdom localStorage tests) | Use Node 22 (`mise exec node@22 -- task validate`). |
| `yarn install` appears to hang | corepack download prompt waiting for input | `COREPACK_ENABLE_DOWNLOAD_PROMPT=0 yarn install --frozen-lockfile < /dev/null` |
| `yarn test` / `task ui:test` never exits | `vitest` starts in watch mode | Use `task ui:test:ci` (`vitest --watch=false`) |
| `warning: VIRTUAL_ENV=... does not match the project environment` | A `VIRTUAL_ENV` from a parent folder leaks into `uv` and tools run in the wrong environment | `unset VIRTUAL_ENV` before running `task`/`uv` |
| `ruff format --check` flags files in `.agents/` or `.claude/` | APM-installed third-party skills contain Python and Markdown | They are excluded in `pyproject.toml` (`[tool.ruff] exclude`); keep new managed folders in that list |
| Running a long task in a shared terminal gets `^C` / exit 130 | Another command typed into the same terminal interrupts it | Run long jobs detached (`nohup ... &`) and read the log file |
| `semgrep --config auto` fails with "Cannot create auto config when metrics are off" | `--metrics=off` is incompatible with `--config auto` | Do not pass `--metrics=off`, or use an explicit config |
| `timeout` command not found | macOS has no GNU `timeout` | Run without it, or `brew install coreutils` |
| Vitest logs `Logout API call failed: Error: Unauthorized` / `Woe, exception be upon ye` | Expected output from tests that exercise error paths | Not a failure; check the summary line |
| The frontend runs unexpected versions (for example Nuxt 4 on a Nuxt 3 commit) | `frontend/node_modules` was left over from another checkout (a `.pnpm` folder is the giveaway) | Delete `frontend/node_modules`, run `yarn install --frozen-lockfile`, then do the preflight in [first-time setup](first-time-setup.md) |
| `yarn lint` reports many `vue/multi-word-component-names` errors for files under `pages/` | `.nuxt` is missing or was generated by another Nuxt version | Run `yarn nuxt prepare` (CI does this before linting) |
| Backend exits at startup with `Can't locate revision identified by '<id>'` | `dev/data/mealie.db` was created by a newer commit | Use a fresh clone, or `task dev:clean` (destroys all dev data) |
| Backend logs `Address already in use` on port 9000 | A failed earlier start left a uvicorn process running | `lsof -nP -iTCP:9000 -sTCP:LISTEN`, stop that process, start again |
| Many pytest tests fail with `readonly database` or `disk I/O error` | Two pytest runs share the SQLite file in `tests/.temp` | Run one pytest at a time; `rm -rf tests/.temp` if it is corrupted |
| A full `pytest` run looks hung | The backend suite runs serially (no xdist at this commit) and takes several minutes | Check CPU with `ps`; run it detached and read the log |
| 3 failures in `test_create_timeline_events.py` in the evening (US time zones) | The scheduler selects meal plans by local date but the tests create them with the UTC date; they differ after 17:00 PDT | Re-run when the two dates agree; this is not a regression |
| `docker: command not found` from a container task | Docker is not installed | The container tasks fall back to Podman automatically; if Podman cannot connect, run `podman machine start` |
